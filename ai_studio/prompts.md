1. Prompt técnico

Prompt utilizado:
Explica de manera técnica, clara y estructurada cómo funciona un modelo de clasificación de texto basado en Transformers. Incluye:
Flujo de procesamiento
Tokenización
Embeddings
Atención (Self-Attention)
Capa final de clasificación
Limitaciones del modelo
Un ejemplo sencillo explicado paso a paso



Explica de manera clara y resumida cómo funciona un modelo Transformer y cuál es su papel dentro de la inteligencia artificial moderna.

Resumen del resultado:
El modelo explicó la estructura básica de los Transformers: embeddings, mecanismo de atención, codificadores, decodificadores y procesamientos paralelos. La respuesta fue clara y útil para complementar la comprensión técnica del laboratorio, mostrando cómo estos modelos procesan secuencias de texto de forma más eficiente que los métodos tradicionales.


2. Prompt creativo

Prompt utilizado:

Imagina que eres un asistente digital para estudiantes. Crea una explicación creativa y motivacional para un estudiante que está teniendo dificultades en matemáticas. Usa analogías simples, tono empático y un ejemplo práctico.




Escribe un mensaje motivacional dirigido a un estudiante que está preocupado por no entender matemáticas.

Resumen del resultado:
El modelo generó un mensaje empático, positivo y motivador. Esta respuesta evidencia cómo los modelos generativos pueden servir como herramientas de apoyo emocional dentro del entorno educativo.



3. Prompt con temperatura ajustada

Prompt utilizado:

Reescribe el mensaje motivacional anterior, pero hazlo con un estilo más creativo, usando metáforas y un tono más emocional.




Genera un mensaje motivacional para un estudiante, pero con una temperatura de 0.9 para hacerlo más creativo.

Resumen del resultado:
La respuesta fue más expresiva y más libre comparada con el prompt anterior. Se observó claramente que al aumentar la temperatura el modelo produce contenido más creativo y menos rígido. Este experimento permitió entender cómo la temperatura afecta la creatividad y variación del texto generado por IA.
